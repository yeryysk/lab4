# Практична робота №4: Динамічні масиви (Власна реалізація Vector/ArrayList)

## Мета роботи
Розробити власний generic-клас MyDynamicArray<T> на базі статичного масиву, реалізувати стратегію геометричного подвоєння ємності та дослідити амортизовану складність операцій.

## Виконані завдання
У ході роботи було реалізовано базовий функціонал динамічного масиву (Add, PopBack, InsertAt, індексатор) та всі три індивідуальні варіанти:

1. Варіант 1: Додано метод RemoveAt(int index) для видалення довільного елемента зі зсувом усіх наступних елементів ліворуч.
2. Варіант 2: Додано механізм зменшення ємності (Shrink). Якщо після видалення елемента Count <= Capacity / 4, місткість масиву зменшується вдвічі для економії оперативної пам'яті.
3. Варіант 3: Клас реалізує інтерфейс IEnumerable<T> за допомогою yield return, що дозволяє перебирати елементи масиву через цикл foreach.

## Аналіз амортизованої вартості (Висновки)

1. **Моменти виклику Resize:** Метод Resize викликається виключно тоді, коли кількість елементів _count досягає поточної місткості масиву _items.Length (тобто масив повністю заповнений). Оскільки місткість збільшується вдвічі, це відбувається на 1, 2, 4, 8, 16... елементах.
2. **Амортизована складність Add (Push):** Хоча сама операція копіювання в Resize займає час O(n), вона відбувається геометрично рідко. Загальна кількість операцій копіювання при додаванні N елементів становить 1 + 2 + 4 + ... + N/2 < 2N. Отже, загальний час додавання N елементів — O(N).
3. Висновок: Амортизована (середня) складність методу Add становить O(1). Додавання одного елемента в середньому вимагає константного часу.
4. Складність інших операцій: 
   - RemoveAt, InsertAt — O(n), оскільки вимагають зсуву елементів.
   - PopBack — O(1).
   - Shrink — амортизована O(1), оскільки поріг зменшення (1/4) відрізняється від порогу збільшення, що запобігає частим перевиділенням пам'яті (thrashing).

## Як запустити
Проєкт написаний на C# (.NET 8). Для запуску необхідно скомпілювати файл Program.cs у будь-якому середовищі розробки (Visual Studio, VS Code, Rider) або через консольний рядок dotnet run.
